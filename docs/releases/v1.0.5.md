## CodexTaskbar v1.0.5

- 修复底部常驻状态条初始化时窗口尺寸与圆角裁剪区域不一致的问题，避免额度文字和百分比被裁掉。
- 窗口尺寸变化时同步更新裁剪区域；缩放、贴边收起和展开后重新绘制状态条。

适用于 Windows 10 / 11 x64。下载 `CodexTaskbar.exe` 即可运行，包含 .NET 运行时。

更新时先从程序菜单退出旧版本，再替换程序文件。现有用户配置保留。
附件 `SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。

### English

- Fixed mismatched window and rounded clipping bounds during status-strip initialization, which could clip usage labels and percentages.
- Keeps clipping bounds in sync with size changes and redraws the strip after scaling, docking, and expanding.

For Windows 10 / 11 x64. `CodexTaskbar.exe` includes the .NET runtime.

Exit the previous version before replacing the executable. Existing user settings are preserved.
See `SHA256SUMS.txt` for the download's SHA-256 checksum.
